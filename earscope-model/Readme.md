## 🔆 Setup and Run Project

### 1️⃣ Create Virtual Environment

**Linux**

```bash
python3 -m venv venv
```

**Windows**

```bash
python -m venv venv
```

### 2️⃣ Use the Virtual Environment

**Linux**

```bash
source venv/bin/activate
```

**Windows**

```bash
venv/Scripts/activate
```

### 3️⃣ Install all Package

```bash
pip install -r requirements.txt
```

### 4️⃣ Run App

**Web Based**

```bash
python app.py
```
